# 🎨 AI Image Generator

A modern web app for generating images from text descriptions using AI. Built with vanilla JavaScript, HTML, and CSS — no frameworks required.

## Live Demo

**[https://saurav-sarkar-1.github.io/ai-image-generator/](https://saurav-sarkar-1.github.io/ai-image-generator/)**

## Features

- 🌸 **Pollinations AI** — free, no sign-up, works instantly
- 🤗 **Hugging Face** — free token, uses Stable Diffusion XL
- 🎨 **Stability AI** — paid, highest quality
- ✨ Prompt enhancer with one click
- 📐 Multiple image sizes (256×256, 512×512, 1024×1024)
- 👍 Feedback and iterative improvement loop
- 📜 Prompt history tracking
- 💾 Download generated images

## Getting Started

Open the [live demo](https://saurav-sarkar-1.github.io/ai-image-generator/) directly — no setup needed.

To run locally, just open `index.html` in your browser.

## Services

### Pollinations AI (Recommended)
- Free, no API key required
- Limit: 1 image per 45 seconds per IP on the free tier
- Uses the Flux/Sana model

### Hugging Face
1. Sign up at [huggingface.co](https://huggingface.co)
2. Go to [Settings → Tokens](https://huggingface.co/settings/tokens)
3. Create a new token (Read role is sufficient)
4. Paste it in the app's Settings section

### Stability AI
1. Get an API key at [platform.stability.ai](https://platform.stability.ai/)
2. Enter it in the app's Settings section
